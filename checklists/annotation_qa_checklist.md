# Annotation QA Checklist

## 1. Task understanding
- [ ] The annotation rule is clear and current.
- [ ] The reviewer can explain the intended outcome in one sentence.
- [ ] Edge cases are documented or flagged for review.

## 2. Data quality
- [ ] No duplicate items.
- [ ] No missing required fields.
- [ ] No corrupted characters or encoding issues.
- [ ] No inconsistent terminology.
- [ ] No unsupported or hallucinated content.

## 3. Safety / accuracy
- [ ] No unsafe medical advice.
- [ ] Units, doses, and thresholds are consistent.
- [ ] Claims are supported by the source or marked uncertain.
- [ ] Absolute wording is reduced when evidence is limited.

## 4. Language quality
- [ ] Vietnamese is natural and grammatically correct.
- [ ] English feedback is clear and concise.
- [ ] Tone is appropriate for the task.
- [ ] The reviewer provides evidence from the exact text.

## 5. Final decision
- [ ] Accept
- [ ] Accept with minor note
- [ ] Reject / needs rework
- [ ] Escalate / needs subject-matter review
